Sécurité Locale

Le proxy n'écoute que sur localhost (127.0.0.1) et n'intercepte que le trafic destiné aux trackers. Vos données de navigation restent privées.

Comment ça fonctionne ?

Découvrez comment RatioGhost s'insère discrètement entre votre client torrent et le tracker.

Sur mobile, faites défiler le schéma horizontalement pour le lire en taille confortable.

1. Requête Announce

Le client envoie ses statistiques réelles : Upload 10MB, Download 5MB.

2. Interception & Altération

RatioGhost capte le paquet et injecte les statistiques modifiées : Upload 50MB, Download 0MB.

3. Validation Tracker

Le tracker privé enregistre les fausses statistiques, augmentant instantanément votre ratio de partage.

Configuration Simple & Rapide

Suivez ces quelques étapes pour rediriger les annonces de votre client torrent favori.

  1. Lancez RatioGhost en tâche de fond.
  2. Allez dans Outils ➔ Options (ou appuyez sur Alt + O).
  3. Cliquez sur l'onglet Connexion dans le panneau latéral.
  4. Faites défiler jusqu'à la section Serveur Proxy :
    • Type : Sélectionnez HTTP
    • Hôte/Adresse : Entrez 127.0.0.1
    • Port : Entrez 3773
  5. Cochez les options suivantes :
    • Utiliser le proxy pour la transmission de torrents
    • Effectuer les recherches de noms d'hôtes via le proxy
    • ❌ Ne cochez pas Utiliser le proxy pour les connexions de pairs.
  1. Lancez RatioGhost en tâche de fond.
  2. Allez dans Options ➔ Préférences (ou appuyez sur Ctrl + P).
  3. Cliquez sur l'onglet Connexion dans le menu gauche.
  4. Dans la section Serveur Proxy :
    • Type : Sélectionnez HTTP
    • Proxy : Entrez 127.0.0.1
    • Port : Entrez 3773
  5. Cochez impérativement :
    • Résoudre les noms d'hôtes par le proxy
    • Utiliser le proxy pour les communications avec le tracker
    • ❌ Ne cochez pas Utiliser le proxy pour les connexions P2P.
